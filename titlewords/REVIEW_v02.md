# タイトルワード分析 — 辞書v0.2.1 レビュー（2026-11-27）

## 実施した修正（v0.1 → v0.2 → v0.2.1）
1. **ラクス**: キャラ辞書から削除せず、使われ方で判定する専用ルールにした。
   - フルネーム表記（ラクス・クライン／ラクスクライン、原文照合）→ 確定
   - 他キャラが明示されている／ブランド定型位置（末尾コード直前・定型語の後）→ タグにせず「除外」として記録
   - SEED明示（ガンダムSEED・SEED・DESTINY）の文脈のみ → 確定
   - 単独で根拠不足 → 分類保留
2. **着衣状態の分離**: ヌード・全裸・裸体・トップレス・着衣は構図/画角へ混ぜず、衣装軸の下位区分 group=着衣状態 に置いた。衣装軸の group は 一般（コスプレ）／衣装名（水着・メイド等の具体名）／着衣状態 の3区分。
3. コスプレ（衣装・一般）、アイドル、スーツ、ボンテージ、乳首、まんこ、デカ乳（巨乳の表記揺れ）、毛利蘭、アーニャ、遠坂凛、接写、マンチラ、愛液、未亡人、オフィスレディ（OLの表記揺れ）、実写風を追加。ポルノ・コミケ・出品者ブランド等は軸対象外へ。キリル類似文字（М等）の正規化と、ラテン文字トークンの小文字照合（ai→AI）を追加。

## 検証方法と結果（分類率と正解率は分けて表示する）
- **回帰確認**: v0.1 と同じ500件（seed DB、月×価格帯層化、シード固定）を v0.2.1 で再分類。
- **未使用サンプル**: 自前収集DB（2026-11-04〜11-26）から新規300件（価格帯層化、別シード）。
- **レビュー範囲**: キャラ名・作品名は両サンプルの全インスタンス（確定・保留・除外あわせて186件）を目視確認。他6軸は未分類上位の全件確認と抽出スポットチェックに留まる（全件レビューではない）。
- **分類率（タグが付いた割合。正解率ではない）**: 回帰500件 95.8% / 新規300件 93.7%。軸別は stats_*.json を参照。衣装は 25.6%→56.2%（コスプレと着衣状態の取り込み）、構図/画角は着衣状態を分離したため 11.0%→9.2%（定義変更による低下で、悪化ではない）。

## レビューで確認できた誤りと対処
- 回帰500件: ラクスのブランド誤判定12件 → 全て除外として記録され、キャラ名タグは付かなくなった。確定タグ内の明確な誤りは0件。
- 新規300件: ラクスはフルネーム確定4件（全て本人作で正しい）、除外8件（全てブランド用法で正しい）。
- レビュー中に見つけた不具合2件は v0.2.1 で修正済み:
  1. キーワード詰め込み型タイトルで「ガンダム」文脈だけでラクスが確定してしまった1件 → SEED明示がある場合のみ確定に絞り、当該件は保留になった。
  2. 「ラクスクライン」（中黒なし）がトークン化の都合で取りこぼされた2件 → フルネーム照合を原文照合に変えて確定するようになった。
- 残る既知の境界例: オリジナル作の同名キャラ（ナミ、アスナ）はタグが「その名前」を主張する以上は誤りと断定しない。作品名との組合せで読む前提を辞書の注記に明記した。

## 未分類の上位（次の辞書候補）

## 全件適用の前提
- 全件実行時は採用データの範囲・件数・辞書版を実行時に固定して index に記録する（DATASET.md 参照）。
- 分類は辞書照合のみの再現可能な処理のまま。AIは候補抽出とレビューに限定する。
